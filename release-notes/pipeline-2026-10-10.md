## English

**Category: Release/deployment pipeline · Existing launcher 0.2.16 and server 0.4.3 are unchanged**

### Changes

- Extend the existing bilingual workflow through launcher download-site deployment after both desktop builds and the immutable GitHub Release succeed.
- Reuse unchanged published packages for configuration-only updates, checking original provenance, current launcher source fingerprint, actual Windows/macOS versions and all GitHub SHA-256 digests.
- Generate deployment-only PHP from the maintained configuration template, replacing launcher version, bilingual update notes, URLs and verified hashes while preserving server routes, announcements and interface policy.
- Stage and back up outside the public 1Panel site, validate PHP in its existing container, verify both HTTPS downloads before activating configuration, then verify the complete public JSON and downloads again.
- Let the domestic download server pull public Release packages through a configured HTTPS acceleration source, accepting only original GitHub sizes/hashes; fall back to GitHub/SFTP and reuse verified existing packages for config-only changes.
- Retire only older launcher packages with exact managed filenames after verification. Preserve private rollback copies, unrelated files and player game resources.
- Pin SSH host identity, keep credentials in Actions Secrets, hold a transaction lock and recover ordinary connection interruptions. An unfinished hard-interrupted transaction stops later deployments for inspection.

### Compatibility

No runtime version is increased and no existing Release is overwritten. The portal remains separate. US game-server deployment stays automatic; China game-server deployment remains a separately requested local operation.

## 简体中文

**分类：构建发布与部署流水线 · 既有启动器 0.2.16、服务端 0.4.3 运行代码不变**

### 更新内容

- 既有双语工作流延伸到启动器下载站：两个桌面平台及不可覆盖的 GitHub Release 成功后自动部署。
- 仅修改配置时复用已发布安装包，核对原构建来源、当前启动器源码指纹、Windows/macOS 真实版本及全部 GitHub SHA-256。
- 从维护用配置模板生成部署 PHP，只替换启动器版本、双语更新说明、下载地址和真实哈希，保留线路、公告及接口规则。
- 在 1Panel 公共目录之外暂存和备份，用既有 PHP 容器检查语法，先核对两个 HTTPS 下载再启用配置，随后再次核对完整线上 JSON 和下载。
- 国内下载服务器通过配置的 HTTPS 加速入口拉取公开 Release 包，只接受原 GitHub 大小与哈希；失败后尝试 GitHub/SFTP，配置更新复用已核验的已有包。
- 验证成功后仅清理文件名严格匹配的较旧启动器包；保留站外回滚副本、无关文件及玩家游戏资源。
- SSH 指纹固定校验，凭据使用 Actions Secrets；事务锁覆盖全部步骤，普通连接中断执行回滚。强制终止留下的未完成事务会阻止后续部署并要求检查。

### 兼容说明

不升运行版本，不覆盖既有 Release。门户网站仍独立维护；美国游戏服务端继续自动部署，中国游戏服务端仍在明确要求后通过本机部署。
