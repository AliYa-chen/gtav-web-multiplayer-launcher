# 远程启动器配置

启动器固定读取 [`https://oss.2t.hk/gtav/`](https://oss.2t.hk/gtav/)，游戏内的公共在线模式提示和桌面公告使用同一份配置。该接口可由独立的 [index.php](../remote-config/index.php) 提供，响应内容仍为 JSON。只有 `{"oltitle":"https://gtav.2t.hk"}` 的配置仍然有效，不要求一次性补齐所有字段。

配置请求在后台运行，联网总超时为 8 秒，最多跟随 3 次 HTTPS 重定向；配置体积最多 256 KiB。成功后在启动器自己的应用缓存目录保存最后一份有效配置。断网、请求失败或配置格式错误时优先使用这份缓存，没有有效缓存时使用内置默认值，并在界面说明配置来自缓存或默认值。读取不到远程配置不会妨碍已经准备好的本地游戏启动。

所有内容都作为普通文字显示，不支持 HTML、JavaScript 或远程命令。链接只接受不包含用户名、密码的 HTTPS URL。远程配置不能指定本机文件、游戏数据路径、引擎补丁或执行命令，也不会改动玩家的游戏资源包。

PHP 接口的 `ALLOWED_ORIGINS` 默认使用 `['*']`，允许所有网站读取这份公共配置，响应为 `Access-Control-Allow-Origin: *`。如需限制来源，删除 `'*'`，改为具体地址数组，例如 `['https://gtav.2t.hk', 'http://localhost:1420']`。来源需包含协议和非默认端口；此接口不启用跨域 Cookie 凭据。

## 字段

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `oltitle` | 字符串 | 原生在线菜单状态文字的内容；可填写 HTTPS 地址或单行说明，最多 160 字。 |
| `website` | HTTPS URL，可省略 | 启动器的站点入口。 |
| `server` | 对象，可省略 | 默认公共战局地址及显示名称。 |
| `server.address` | 字符串 | IP 或域名，可带端口；例如 `183.66.27.21:47485`，不带 `ws://` 前缀。IPv6 加端口时使用方括号。 |
| `server.name` | 字符串，可省略 | 公共战局显示名称，最多 80 字。 |
| `server.status_url` | HTTPS URL，可省略 | 公共战局状态页面链接，不表示启动器已探测服务器在线。 |
| `announcements` | 数组，可省略 | 最多 24 条公告。每条含 `title`、`body`，可含 `date` 和 HTTPS `url`。 |
| `update.latest_version` | SemVer 字符串，可省略 | 最新启动器版本，例如 `0.1.2`，按数值比较版本；支持 `v` 前缀和预发布版本。 |
| `update.release_notes` | 字符串，可省略 | 最新版本说明，最多 8192 字；`notes` 是兼容别名。 |
| `update.downloads` | 对象，可省略 | 按平台提供下载文件。建议键名为 `windows_x64`、`macos_arm64`、`macos_x64`。 |
| `update.downloads.<平台>.url` | HTTPS URL | 此平台的安装包或压缩包地址。 |
| `update.downloads.<平台>.sha256` | 64 位十六进制字符串 | 上述文件原始字节的 SHA-256，下载后用于完整性校验。 |

`latest_version`、`downloads`、`release_notes` 也可以直接放在 JSON 根对象中；根对象同名字段优先。`latestversion` 是 `latest_version` 的兼容别名。未知字段忽略；已知字段类型错误、不安全链接、非法版本号或不完整文件哈希会使此次配置无效，保留之前的有效缓存。

公告标题最多 120 字，正文最多 4096 字，日期是最多 40 字的普通显示文本。公告中的换行可保留，标题链接不会作为 HTML 插入。远程版本和下载入口只有配置了对应平台有效链接与 SHA-256 才能使用；示例中的地址和全零哈希需要替换为实际发布文件，不要直接作为生产配置。

完整示例见 [remote-launcher.example.json](remote-launcher.example.json)。发布时先上传下载文件，计算文件 SHA-256，再更新配置中的版本、地址、哈希和公告。例如：

```sh
shasum -a 256 GTA5Data-Launcher-macOS-arm64-v0.1.2-development.zip
```

本版的“下载新版”会打开默认浏览器，下载链接来自已经校验过的配置；启动器不会自动下载、安装或执行该文件，也不会声称已校验浏览器下载的内容。配置中的 SHA-256 可用于下载后的人工校验，后续若加入应用内下载，必须先通过同一校验再提供本地安装包。

macOS 公证、Developer ID 签名以及 Tauri 更新包签名是另外的分发校验要求；此配置中的 SHA-256 只用于检测文件与配置是否一致，不能替代这些签名。远程配置本身不会自动替换正在运行的启动器。

## 后端集成接口

`desktop/src-tauri/src/remote_config.rs` 提供：

```rust
// 放在后台线程调用，cache_path 必须来自 app_cache_dir。
let snapshot = remote_config::load(&cache_path);
let available = remote_config::has_update(current_version,
    snapshot.config.latest_version.as_deref());
let download = remote_config::download_for_platform(&snapshot.config, "macos_arm64");
```

返回的 `ConfigSnapshot` 包含 `config`、`source`（`remote` / `cache` / `default`）、`stale`、`fetched_at`、`checked_at` 和可选 `error`。时间使用 UTC Unix 秒。联网失败后的缓存标记 `stale: true`，来源于有效远程响应时标记 `stale: false`。错误说明不包含认证信息或来自服务端的 HTML 错误内容。
