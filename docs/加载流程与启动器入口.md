## 76% 加载停滞

原 GPU 工作线程首次呈现加载画面时报告 `76% / First frame`，这并不表示游戏世界已经就绪。公共客户端此前仅凭服务端快照完整和角色放置完成就停用本地脚本，还可能提前换模、创建公共实体及修改环境，打断原引擎的启动流程。

现在页面收到原 GPU 发布的真实世界稳定帧 `world: true` 后，才通过启动器自己的共享快照设置 `engine_ready: true`。桥在此之前只准备通信和读取快照，保留加载脚本；随后才执行角色、实体、环境和服务器脚本策略。原网络同步树初始化状态仅用于诊断，不参与就绪门槛。断线后已生效的公共策略保持有效。

2026-10-09 已通过本地源码页面连接实验线路，在真实 GTA 中完成加载并显示公共出生区和在线角色。本地运行截图保存于 `docs/snapshot/loading-readiness-online-success.jpg`，不随源码仓库发布。该运行记录对应本次加载恢复。

## 本机与共享入口

| 入口 | 模式和身份选择 |
| --- | --- |
| 本机启动器 | 选择公共战局、故事或自由沙盒；公共战局昵称、线路、角色预设由启动器填写 |
| 朋友共享首页 | 保留故事、沙盒和在线模式选项；在线加入时在网页填写自己的昵称、服务器与预设 |

启动器直达页面隐藏模式选择，只显示右下角加载状态、百分比和圆环。共享邀请始终指向无身份参数的根首页；不会复制主机昵称、角色种子或服务器选择。证书引导的目标只允许同一启动器的首页或经过校验的入场路径。

启动器服务器下拉框直接显示远程接口的 `address`，只允许选择配置中的可用线路，不能手动输入其他 IP。启动器界面使用浏览器请求该线路配置的 HTTPS 健康接口，校验公共战局响应并测量请求完成延迟；三秒超时、缺少或不安全的健康端点、错误状态或不兼容响应都标为不可用。界面每三十秒或恢复前台时复查，点击进入前再次检查，后端重新确认线路属于当前配置。可点击重新检测；已选失效线路不会静默改成另一条。故事和沙盒不受健康检查影响。

连接协议和代理路径在内部保留，不作为下拉文案。一次性入场参数校验成功后写入会话存储并从地址栏移除，刷新会恢复当前战局身份。共享朋友在线表单继续允许自己输入昵称和选择服务器。

## 日志请求

`POST /log` 的 `204` 表示主机已接收本地诊断日志。适配器按类别、实体或脚本去重，合并最新状态后有界批量发送；最多一个请求在途，日志失败不阻断战局。血量、武器、人数或天气等真实变化仍保留，单独递增的同步版本不会持续产生请求。连接日志也按阶段去重，重连时重新记录生命周期。

调试详细资源日志仍需显式开启。普通加载页隐藏技术日志和底部进度横条；错误和加载状态继续可见。
