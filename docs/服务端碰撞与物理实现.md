# 服务端碰撞、弹道与导航：0.4.1

本轮已读取本地真实碰撞和道路资源，并把几何查询、弹道推进和道路路线接入 Java 服务端。原先只有 `ped_capsules_aim_terminal` 的说明已过时：当前新客户端声明 `physics_queries` 后，瞄准坐标用于确定发射方向，不再直接充当已验证的落点。服务器仍不是完整 RAGE 物理运行时；以下区分实际实现与仍需补齐的范围。

## 本地游戏提供的依据

- 读取 1,528 个 RPF 目录，定位 15,557 个 YBN、5,853 个 YMAP、383 个 YND 和 4,404 个 YNV。索引数量包含不同关卡和变体，不等于独立世界对象数量。
- 出生区 600×600 米范围导出 134 个 YBN 的 301,339 个真实世界坐标三角形，约 12 MB。由本地 WASM 函数确认量化顶点、复合变换和材质编号，未以模型 AABB 代替碰撞面。`(711,-1088)` 垂直射线的地面交点为 `z=21.413179684774207`。
- 完整解析道路 IPL，得到 77,824 个节点、81,133 条连接；保守可导航连接为 24,227 条。真实图上已计算 12.67 公里的路径，未运行车辆实驾。
- 提取 213 种材质的射穿、透视、摩擦和弹性属性，以及 91 项原始武器的速度、重力、反弹、黏附、延迟爆炸等显式参数。缺失参数保留未知值，不从字段名推测引擎默认值。

资源和结构证据见 [碰撞资源导出](本地碰撞资源与服务端导出.md)、[道路图](服务端道路图.md)。生成器固定资源 SHA-256，所有派生几何位于被 Git 忽略的 `server/world-data/`；原始游戏文件不修改。

## 服务器如何判定

`StaticCollision` 加载三角形并建立 BVH 空间索引，提供最近相交点和表面法线。`MaterialCatalog` 同时识别 YBN 的材质编号和原生查询返回的 `名称_编号` hash。射击与视线分别使用 `SHOOT_THRU` 和 `SEE_THRU`，不会把这两个属性混用。

已导出的静态面用于约束结果；没有命中静态面不代表整个区域没有障碍，因为还有未导出的碰撞类型。服务器向指定、已声明能力的客户端发送带唯一 ID 和期限的 `collision_query`，客户端只执行服务器给定的轨迹，回传几何候选。查询在有效脚本回调中调用已核实的原生异步 shape-test，范围限定为观察者附近已加载的碰撞。

服务器校验观察者身份、世界 epoch、一次性票据、1.5 秒期限、结果数量、碰撞点在线段上的位置和单位法线。客户端的“无遮挡”不能覆盖服务器已有的静态墙面。可射穿表面使用新票据继续检测后方，最多八层，不延长原期限。失败、无资源和超时不被当作“无遮挡”。该路径仍依赖受分配引擎如实观测，不能宣称服务器独立重算了所有未导出的地图。

枪械和霰弹逐条使用实际命中射线；伤害暂存，几何完成后才提交。受害者代次变化会使旧结果失效。NPC 射击也接入相同遮挡路径。近战已有距离和朝向判定，并增加已提取静态墙面约束；尚未添加完整的近战骨骼碰撞。

## 投射物与表面反应

具有物理查询能力时，服务器按 `p(t)=p0+v0*t+(0,0,-9.81*gravity*t²/2)` 推进运动段，按有限时间片向地图查询轨迹，并独立检查已登记角色胶囊。短瞄准终点不会让弹丸在空气中自动落地。

表面命中后根据武器是否允许反弹、是否黏附或撞击销毁处理：

- 反弹使用真实材质弹性与摩擦。切向速度衰减和最多八次反弹是公开的服务端玩法策略，尚未复现 RAGE 完整接触求解器。
- 榴弹读取明确的撞击后计时；手雷保留定时爆炸。黏弹在确认表面停留，遥控引爆仍只属于原投掷玩家；等待碰撞确认时不会抢先爆炸。
- 爆炸和持续区域伤害在提交前查询到角色的遮挡，失败不盲目扣血。该模型仍是中心到角色的有限射线，并非完整压力传播。
- 客户端只显示服务器运动段、反弹更新和无伤害爆炸效果，不在本地第二次计算伤害。

旧协议/明确禁用数据的测试模式保留旧简化路径；`/health` 和 `/world` 的 `collision` 字段显示实际加载的三角形、查询能力、完成和超时计数。不能仅见到版本号就认定静态数据已安装。静态三角形只有命中证据，没有完整覆盖证明；没有可用原生观察者的物理弹丸可能取消，不能把取消描述为确定撞墙。

## 道路与 AI

服务器决定交通、逃离和警察驾驶路线，沿真实道路连接计算 A*，下发路线前方的目标点。车辆出生点先吸附到道路并检查间距，路点高度加一米用于初始放置。客户端执行转向、加速、局部避障和接地。

尚未核实的单行方向、转向限制节点被保守排除；没有路径时发布 `idle / road_unavailable`，不回退为穿过建筑的直线。该图是车辆道路中线，不是行人 YNV 导航网格。

## 本地运行与部署

```sh
python3 -B tools/extract_road_network.py
python3 -B tools/export_world_collision.py
python3 -B tools/build_multiplayer_server.py
python3 -B tools/build_multiplayer_client.py
java -jar server/multiplayer-server.jar --world-data server/world-data
```

Java 运行时不需要 Python 或原始游戏包，只需要 JAR 和提取好的数据目录。默认读取 JAR 同目录的 `world-data`；`--world-data none` 明确使用无图协议测试模式。指定目录内文件损坏会启动失败，不静默退化。没有文件时健康接口明确报告不可用。

现有 `build_server_bundle.py` 默认不包含游戏派生数据。部署此功能时需同时复制自己的 `world-data/roads.bin`、`world-data/collision.bin` 及对应审计元数据，并更新客户端在线引擎与 JS。2026-10-09 已把 JAR 与这批道路／碰撞数据部署到公网主线路及实验线路，两个 HTTPS 健康接口和 WSS 身份／完整快照检查均通过。

## 验证与后续范围

已运行资源解析、材质、道路、服务端碰撞、票据/超时、弹道/黏弹和实际 Java WebSocket 到客户端模块的测试。跨层测试中的 native 是模拟器：分别返回铁丝网后墙和无遮挡，验证服务器拒绝前者的伤害、确认后者 25 点伤害。原始 WASM 通过 ABI 检查及编译。尚未启动两个真实 GTA 客户端做画面和原生物理验收。

仍需补齐：YBN 的 box/capsule/sphere/cylinder 原语、YDR/YFT 内嵌碰撞与 YMAP 实例、流式层级和破坏状态、移动载具上的黏附、有限厚度穿透、全地图行人导航、火势传播及完整电击动作。现在已实现可射穿材质后的连续查询，并不代表任意材质的数值穿透已经还原。原始电击持续参数已提取，但当前生命伤害与动画尚未完整复现原生电击状态。

最后一次本地持续验证加载了真实碰撞和道路数据：八人运行 30 秒，接受 4,632 次玩家状态与 292 次实体批次，39,556 次增量接收无序号缺口、无错误。该持续测试没有发起原生碰撞查询；查询与扣血由单独的跨层测试验证。271 项 Node 测试、原生 ABI/隔离测试及上述资源/Java 回归已通过。
