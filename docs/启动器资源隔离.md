# 启动器与玩家游戏资源隔离

启动器只包含网页、多人适配逻辑、本地 HTTP 服务与构建工具。玩家自行准备匹配版本的浏览器游戏资源；启动器不会下载、复制、移动或覆盖这些资源。原版 PC GTA V 安装目录不能直接替代这里的 WASM 浏览器资源结构。

## 分开的三个目录

| 目录 | 用途 | 写入规则 |
| --- | --- | --- |
| 玩家选择的游戏资源目录 | `data/manifest.json`、资源包与 `b/8b0b5899ed/game.wasm`、`game.js` 等原浏览器引擎文件。 | 只读，不能生成字体别名、修改清单或输出多人副本。 |
| 启动器 `client/` | HTML、加载脚本和多人 JavaScript。 | 更新启动器时可替换其源码。 |
| 启动器 `client/runtime/` | 本机构建的 `game-multiplayer.wasm` 及其 `game-multiplayer.json` 证据。 | 独立生成；不分发游戏引擎，不写回玩家目录。 |

目前支持的原始 `game.wasm` SHA-256 为：

```text
11ca8d2c04c5e843d18ff4aea4899d72c86973c6b031df334e67c446b2ae83e0
```

构建器和本地服务都会核对版本。其他引擎版本不能靠同名文件跳过兼容检查。多人 WASM 补丁是从玩家本机提供的原引擎生成的独立运行副本；原引擎继续保持原字节。

## 使用外部资源

资源总目录必须同时包含 `data/` 和 `b/8b0b5899ed/`，例如：

```text
D:/GTA浏览器资源/
├── data/manifest.json
├── data/common/...
├── data/x64/...
└── b/8b0b5899ed/
    ├── game.wasm
    ├── game.js
    ├── io_worker.js
    └── wgpu_worker.js
```

安装 Python 3.11 或更新版本，在启动器目录执行：

```sh
python3 tools/build_multiplayer_client.py --game-dir "D:/GTA浏览器资源"
python3 serve_local.py --game-dir "D:/GTA浏览器资源" --multiplayer --open
```

`--game-dir` 也接受上述目录中的 `data` 子目录，本地服务会定位其父资源根，不移动文件。缺失清单、原引擎或必需 Worker 时启动会给出中文错误；不会自动下载游戏。

如将生成物放在另一处，构建和启动时使用同一个 `--runtime-dir`：

```sh
python3 tools/build_multiplayer_client.py --game-dir "/Volumes/GTA资源" --runtime-dir "./archive/cache/launcher-runtime"
python3 serve_local.py --game-dir "/Volumes/GTA资源" --runtime-dir "./archive/cache/launcher-runtime" --instances 2 --multiplayer
```

生成目录必须位于玩家资源目录之外。`--instances 2` 仍用不同端口隔离浏览器存储，两个客户端连接同一个远程公共战局。客户端不需要本地 WebSocket 服务；只有明确使用 `--start-room-server` 才启动本机测试服务端。

浏览器的 `/data/...` 请求和批量读取接口都定位到所选资源目录；`/b/8b0b5899ed/game-multiplayer.wasm` 只定位到 `--runtime-dir`。即使旧游戏目录残留同名多人副本，也不会作为新的启动器运行副本回退使用。

## 字体修复的隔离边界

早期本项目在 `data/` 根增加了五份字体别名，并给 `data/manifest.json` 追加记录。这是已有目录的历史状态；新的启动器不得继续靠写清单或复制字体到游戏目录实现修复。已存在的别名与清单保持原样。

实际原资源位置为 `common/data/Scaleform/gfxfontlib.gfx`，其余语言字体来源于玩家自己的 `x64/data/cdimages/scaleform_platform_pc.rpf`。它们不能被描述成原资源树已经独立存在的 `font_lib_*.gfx` 文件。字体导入须由启动器在内存或隔离运行目录处理，从玩家已有文件只读取得；缺失时明确报告所需文件，不下载字体或修改原清单。引擎 MEMFS 是本次游戏进程的内存文件系统，写入其中不等同于写玩家硬盘资源。

如果玩家资源本身已含旧字体别名，HTTP 服务仅只读提供这些文件；启动器打包不会把它们收进去。字体来源、格式兼容和语言选择由加载器负责，资源服务不会伪造 manifest 条目。

## 发布源码启动器

```sh
python3 tools/build_launcher_zip.py
python3 tools/build_launcher_zip.py --include-server --output "./archive/packages/launcher-with-server-source.zip"
```

构建工具采用源码白名单：网页文本源码、本地服务、必要 Python 构建工具和本说明。`--include-server` 只增加 Java 源码、服务端说明与构建脚本。包内没有 `gta5data/`、WASM、RPF、字体、标题图片、生成 runtime、JAR、日志或机器缓存，解压后仍需玩家准备游戏资源，并在本机生成运行副本。

这是一份 Python 源码启动器包，要求系统安装 Python；不是已经签名、内嵌 Python 的桌面可执行程序。如果以后提供 EXE/App，资源目录选择、只读保护、原引擎哈希核验和分发边界仍必须保持。诊断日志默认写启动器 `docs/snapshot/`，不能通过 `--log-file` 把日志写进玩家资源目录。
