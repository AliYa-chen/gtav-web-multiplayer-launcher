# 0.2.15 多人同乘与公开源码

0.2.15 修复已有玩家司机时第二名玩家无法上车的问题。原生入车任务返回驾驶位时，客户端根据服务端座位表选择真实空乘客位；空驾驶位和抢 NPC 驾驶位仍保留原行为。满车、无有效原生座位或未就绪角色不会发送错误的入座请求。

服务端始终原子检查自己的玩家角色、当前距离、有效生命周期和当前座位占用。它本来就支持同代次旧版本请求，本次没有放宽这些验证。0.4.3 修正乘客离车误清司机待确认模拟授权的问题；只有司机离车才清除该车的授权邀请。

客户端按服务端确认的具体座位核对真实原生占位，不能仅因在同一辆车就认定成功。先释放失去挂接或占错受管理车辆/座位的已知乘员，再重新挂接，避免两个乘员互相占位死锁。换模和恢复中的本机角色不会误报离车。临时启用原生 flag 184 防止自动挪到驾驶位，解除挂接与断线时恢复角色原值。

`mpSetPedConfigFlag`、`mpGetPedConfigFlag` 沿用经过版本和 ABI 校验的原生命令。原函数体不改，运行副本仍由启动器在游戏目录外生成；新在线副本 SHA-256 为 `24489ede2e5d031573aa9dc2504db7b1d69b0e6afcc9358657f6c2fc6b52d003`。离线副本与原引擎字节一致。

## 公开源码与仓库

仓库已更名为 [GTAV Web Multiplayer Launcher](https://github.com/AliYa-chen/gtav-web-multiplayer-launcher)，并设为公开。官网为 [gtav.2t.hk](https://gtav.2t.hk/)。默认 README 使用英文，[中文 README](../README.zh-CN.md) 独立提供，均说明目录和主要文件作用。

项目自有代码与文档使用标准 [MIT License](../LICENSE)，包含完整授权、免责及责任限制条款。版权声明保留官网和原仓库地址；MIT 不额外要求 UI 署名或公开修改。原游戏资源、引擎和第三方内容不因此获得再分发授权，详见 [NOTICE](../NOTICE.md)。客户端右上角加入可访问的 GitHub 小猫入口，中英文显示，固定通过系统浏览器打开新仓库，不依赖线路接口是否可用。

门户源码位于独立的 `gtav-server-status` 仓库，提交 `586e85a` 加入导航和页脚仓库入口及中英文标签。门户更新文件整理在手动上传包的 `portal/` 子目录，不自动部署。

按维护者要求，测试专用文件已从当前 Git 树移除并加入忽略规则，源码内的测试模块也已移除。仅本机忽略目录保留验证材料；提交内容检查同时拒绝后续误提交测试目录或文件。
