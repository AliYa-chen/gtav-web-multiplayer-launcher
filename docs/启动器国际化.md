# 启动器国际化（0.2.12）

启动器支持「跟随系统」「中文」「English」。语言由启动器保存并统一提供给游戏网页和局域网证书引导页；无需给每个客户端单独设置，也不需要修改游戏服务端协议。

## 使用方法

1. 在启动器的语言选择框中选择语言。
2. 启动器立即更新界面并保存设置。已经打开的游戏网页和局域网引导页会自动读取同一配置。
3. 网页菜单、加入面板、角色预设、线路名称、加载进度、连接状态和桥接通知会随之更新。当前公共战局保持连接。

原游戏菜单使用加载时选择的语言包。运行中切换语言时，网页会提示「游戏菜单语言会在下次进入游戏时应用」；重新进入游戏后生效，不会自动重载当前战局。

| 显示层 | 中文 | English | 生效时机 |
| --- | --- | --- | --- |
| 启动器、游戏网页、局域网引导 | 中文界面 | 英文界面 | 启动器即时更新，网页自动同步 |
| 原生战局状态和战斗通知 | 中文通知 | 英文通知 | 桥接快照更新后生效 |
| 原游戏设置、暂停菜单等资源文字 | 已有 `chinese` 繁体语言包 | 已有 `american` 英语包 | 下一次进入游戏 |

启动器的「跟随系统」由启动器主机解析，客户端网页优先使用这个结果。其他语言的系统使用英语；中文系统使用中文。

## 配置与共享接口

桌面设置保存在启动器自己的应用配置目录中，使用 `language` 字段记录 `system`、`zh-CN` 或 `en`。所有本机 HTTP、局域网 HTTPS 和证书引导 HTTP 服务共享同一份语言状态，客户端端口之间不依赖浏览器存储传递设置。

网页通过只读接口获取当前状态：

```http
GET /api/language
Cache-Control: no-store
```

```json
{"preference":"en","resolved":"en","revision":2}
```

| 字段 | 含义 |
| --- | --- |
| `preference` | 用户选择的 `system`、`zh-CN` 或 `en` |
| `resolved` | 当前使用的 `zh-CN` 或 `en`；Python 开发模式的 `system` 返回 `null`，由浏览器解析 |
| `revision` | 当前启动器进程中的配置版本；重启后可以重新从 1 开始 |

网页可见时以约 2 秒间隔复查配置，恢复可见时立即检查。临时断网会保留最后一次有效的启动器选择。请求顺序校验会忽略晚到的旧响应；网页接受启动器重启后的较小 `revision`。

`POST /api/language` 返回 `405`。网页 URL 中的语言参数不会覆盖启动器设置。语言只能通过桌面启动器选择，或由开发者在 Python 启动命令中指定。

脚本启动方式：

```sh
python3 serve_local.py --language en --open
python3 serve_local.py --language zh-CN --open
python3 serve_local.py --language system --open
```

Python 默认为 `system`，此时各网页使用自己的浏览器语言。多开实例都会获得同一个 `--language` 参数。Python 模式修改参数后需要重新启动本地服务。

## 远程配置中的翻译

已有配置字段继续作为回退值。网站可以提供按语言组织的显示文案；连接端点、下载地址和 SHA-256 不受语言切换影响。

```json
{
  "oltitle": "https://gtav.2t.hk",
  "i18n": {
    "zh-CN": {"oltitle": "公共战局"},
    "en": {"oltitle": "Public Session"}
  },
  "servers": [{
    "id": "main",
    "address": "gtaserver.2t.hk:47485",
    "health_url": "https://gtaserver.2t.hk:47485/47485/health",
    "name": "公共战局",
    "role": "主线路",
    "i18n": {
      "zh-CN": {"name": "公共战局", "role": "主线路"},
      "en": {"name": "Public Session", "role": "Main Server"}
    }
  }]
}
```

桌面远程配置还支持 `i18n[语言].announcements` 和 `release_notes`。Python 游戏网页代理只需要并保留服务器名称、线路角色和 `oltitle` 的翻译。

翻译内容继续经过长度和格式检查。`oltitle` 可以是纯文字或安全 HTTPS 地址；不会执行远程 HTML 或脚本。语言切换会重新显示当前有效快照，不会为这次切换额外请求远程配置。玩家昵称和自定义服务器名称不会被自动改写；缺少显式翻译时，仅翻译项目已知的默认标签。

## 游戏资源保持只读

中文菜单使用当前受支持资源中已有的 `chinese` 繁体包，该资源没有 `chinesesimp` 简体包。启动器通过游戏启动参数选择 `chinese` 或 `american`，不会生成或替换玩家游戏包中的语言资源。

国际化源码位于 `desktop/src/locales/`、`desktop/src/i18n.js`、`client/i18n.js` 及客户端桥。原 `game.wasm`、随包 JS、RPF、字体、脚本和资源清单保持只读；隔离运行副本仍由启动器管理。语言切换不能绕过引擎版本校验。

## 验证范围

回归覆盖启动器翻译、网页配置轮询、隐藏页恢复、启动器重启、远程翻译切换、连接保持、原生通知和原游戏语言参数。Python HTTP 测试覆盖 `GET/HEAD`、`no-store`、拒绝网页修改、启动器字典映射以及临时游戏资源哈希不变。

这些检查不替代真实双客户端游戏画面验收。运行中原游戏菜单的语言包仍需要下一次进入游戏才能切换。
