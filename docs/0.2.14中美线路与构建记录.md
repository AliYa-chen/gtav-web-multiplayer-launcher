## 线路与部署

客户端从远程配置获取地址、端口、HTTPS 健康接口和完整 WSS 端点，不再内置公网默认值，不把空地址回退到本机。Python 与 Rust 代理保留地区和中英字段；显式自定义端口、协议及代理路径继续保留。开发参数 `--start-room-server` 将实际本地启动地址传给本地配置。
