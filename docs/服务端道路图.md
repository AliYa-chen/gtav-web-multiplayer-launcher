IPL 是生成结果，含额外生成节点、展开的默认值，并与部分 XML 属性存在差异。导出器始终采用 IPL 的有效值，XML 差异写入 `roads.audit.json`，不静默覆盖。源 IPL 的 SHA-256 为 `7e682db51eb056bbd22772c5d427b59c7721f016d95e2afe743c423cf3a80b30`，XML 为 `1e3ba02b227463158854c7475c14e82041b30dbca402433fc31b7bac7515ff1e`。

节点有 XYZ、禁用、水路、高速、GPS、隧道、越野、转向限制、大型车辆限制、车流密度、速度类别和街道哈希。连接有首尾节点、宽度、`Lanes In` / `Lanes Out`、窄路、双向 GPS、无车道封闭、捷径和禁止导航等属性。速度类别是原始枚举，不能直接当作米每秒；道路节点 Z 是道路参考高度，不能用作任意地表采样。

## 当前服务端可执行部分

`RoadNetwork` 独立加载紧凑道路文件，对道路段建立空间索引，提供三维最近道路点和有限 A*。最近点使用 XYZ 距离，避免把高架和地面只按 XY 混为同一层。路线沿真实连接前进，保留道路高度。每次最多搜索 20,000 个节点；搜索失败、超预算、缺少资源或距离道路过远均返回明确失败，不生成穿过建筑的直线路线。

当前车道字段相对于首尾节点的方向尚未获得原生执行证据，因此保守过滤所有单行边，不猜测哪一个方向可驶入。禁用、水路、NoGps 节点、禁止导航连接和含未验证转向约束的交叉节点也不用于本轮道路寻路。所有原始车道与节点限制仍保存在数据中，后续验证后可扩展策略。

`WorldAi` 的环境交通、危险逃离和警察驾驶均使用该图。环境交通沿真实邻接选择确定性短路线；追逐与逃离通过 A* 选择路线。驾驶任务只发送沿道路折线前方 12 米的下一目标点，随后根据服务端接受的车辆位置向前推进。目标变化或偏离路线时重新计算，失败重试间隔至少 500 毫秒。没有可用路线则发布 `idle` / `road_unavailable`，不再发布让客户端自行 `DriveWander` 的空目标驾驶任务。

加载道路图时，`WorldService` 在车辆人口生成前将候选点吸附至 60 米内的可用道路，以道路切线计算 GTA 朝向；没有对应道路则跳过该车辆及司机。出生高度暂用道路参考 Z + 1 米，并检查与现有车辆至少相距 6 米。这是生成策略，不等同于悬挂或地面接触求解。未加载道路图的旧测试模式保留原来的网格出生点。

这个保守子图有多个不连通区域，服务端必须检查 `Route.reached()`，不能假定每两个道路点均可达。它是车流道路中线图，不是步行导航网格；不提供道路车道中心偏移、红绿灯时相、动态避障、车辆碰撞或地形碰撞。路线首末点是道路吸附点，不验证实体原位置至吸附点的可通行性。原生车辆控制和局部避障仍由获租约的游戏引擎执行。

接口：

```java
RoadNetwork roads = RoadNetwork.load(path); // 缺少/损坏数据抛 IOException
RoadNetwork.Snap nearest = roads.nearest(new RoadNetwork.Point(x, y, z), 80);
RoadNetwork.Route route = roads.route(start, destination, 80, 4000);
RoadNetwork.Route ambient = roads.cruise(start, headingDegrees, 40, 60, deterministicSeed);
// route.reached(), route.points(), route.length(), route.reason()
```

`nearest` 最大吸附距离为 1,000 米；`route` 只返回道路路线。失败原因包括 `unavailable`、`off_road`、`disconnected`、`route_budget`。`RoadNetwork.empty()` 明确表示道路导航不可用。`metadata()` 提供资源来源、完整节点/连接数量和当前可导航连接数量。

## 数据提取与校验

```sh
python3 tools/extract_road_network.py
```

默认输入来自本机 `gta5data/data/common/data/levels/gta5/`，输出为 `server/world-data/roads.bin` 和 `roads.audit.json`。它们是本地游戏资源派生物，不应提交 Git；服务器部署时需要随本次 world-data 单独带上。

维护者本地回归文件不随源码分发。已有回归覆盖：合成道路的三维上下层区分、路线长度和端点、断路、无图、有限搜索、单行边保守过滤、禁用/禁止导航属性、不可变路线、畸形数据拒绝；另在本机真实图上执行约 12.67 公里、1,152 个路线点的可连通路线验证。该记录对应服务端道路图中的可连通路线。

## GTAROAD1 二进制格式

所有整数和浮点数采用大端，文件长度必须精确符合记录数量：

| 区域 | 布局 |
| --- | --- |
| 48 字节头 | ASCII `GTAROAD1`（8）、节点数 u32、连接数 u32、源 IPL 的 SHA-256（32） |
| 每个节点 24 字节 | x/y/z f32，节点 flags u32，速度类别 u8，special u8，density u8（0～15），保留 u8=0，street hash u32 |
| 每个连接 20 字节 | 起点索引 i32，终点索引 i32，宽度 f32，Lanes In u16，Lanes Out u16，连接 flags u32 |

节点 flags：Disabled=1、Water=2、Highway=4、NoGps=8、Tunnel=16、Off Road=32、Cannot Go Left=64、Left Turns Only=128、Cannot Go Right=256、No Big Vehicles=512、Indicate Keep Left=1024、Indicate Keep Right=2048、Slip Lane=4096。

连接 flags：Narrowroad=1、GpsBothWays=2、Block If No Lanes=4、Shortcut=8、Dont Use For Navigation=16。
